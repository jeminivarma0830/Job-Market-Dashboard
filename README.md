📊 Job Market Dashboard (Power BI)
📌 Overview
This project is an interactive Job Market Dashboard built using Power BI to analyze job trends, salary distribution, and in-demand skills across different roles and locations. The goal is to transform raw job data into meaningful insights that can support better career decisions.

🎯 Objectives
Analyze current job market trends
Identify high-demand skills
Compare salary distribution across roles
Understand location-based job opportunities

📊 Features
Interactive dashboard with filters (role, location, experience)
KPI cards showing key metrics (total jobs, average salary)
Skill demand analysis (Python, SQL, etc.)
Job role distribution and hiring trends
Location-based job visualization

🛠Tools & Technologies
Power BI
Data Cleaning
Data Visualization
Basic Data Analysis

📁 Dataset
The dataset includes job-related information such as:
Job Title
Salary
Location
Company
Skills

(Source: Public dataset from online platforms like Kaggle)

💡 Key Insights
Python and SQL are among the most in-demand skills
Data-related roles offer higher average salaries
Job opportunities are concentrated in major tech locations

🚀 Project Outcome
This project demonstrates the ability to clean, analyze, and visualize data effectively using Power BI while presenting insights in a clear and interactive manner.
